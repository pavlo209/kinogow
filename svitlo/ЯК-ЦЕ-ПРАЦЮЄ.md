# Графік світла, Волинська область

Бот `@volunsvitlo_bot` приймає населений пункт, вулицю і будинок, знаходить чергу відключення і надсилає години на сьогодні та на завтра. Раз на 5 хвилин він перечитує офіційний графік і пише людині, якщо години змінились, відключень немає або з’явився графік на завтра.

Живий бот працює на Cloudflare, не на ноутбуці. Ноутбук потрібен, щоб забрати код, токени і за потреби підключитися тими самими доступами з іншої програми.

## Де що лежить

| Що | Де |
| --- | --- |
| Бот у Telegram | [@volunsvitlo_bot](https://t.me/volunsvitlo_bot) |
| Сторінка і приймач повідомлень | https://pavlo-telegram-bot.pmodsp.workers.dev |
| Код бота на сервері | `svitlo/worker/` |
| Локальна програма на Python | `svitlo/` (`python3 -m svitlo`) |
| Довідник черг | `svitlo/worker/catalog.json` і `svitlo/queue_catalog.json` |
| Доступи для ноутбука | файл `ДОСТУПИ.env` у цьому архіві |
| Код на GitHub | гілка `cursor/volyn-outage-alerts-7a1d`, pull request №10 |

Файл `ДОСТУПИ.env` не завантажуйте в GitHub і не надсилайте в чат. У репозиторії його немає навмисно.

## Що відбувається, коли людина пише боту

1. Telegram надсилає повідомлення на адресу `https://pavlo-telegram-bot.pmodsp.workers.dev/telegram`.
2. Сервер перевіряє секрет вебхука і віддає текст боту.
3. Бот читає населений пункт, вулицю і будинок. Можна трьома рядками або одним: `Луцьк, Волі, 44а`.
4. Назву звіряє з довідником. Зайві пробіли виправляє. Якщо пункт чи вулиця не з Волині, пояснює, що саме не збіглось, і за можливості називає район.
5. У довіднику шукає чергу для цього будинку. Діапазон на кшталт `14-16` — це один будинок, а не номери 14, 15 і 16.
6. Години бере з уже прочитаного графіка Волиньобленерго і відповідає текстом. Під карткою адреси є кнопки змінити і видалити.
7. Адреса зберігається. Далі вона входить у перевірку кожні 5 хвилин.

Кнопки в боті: «Додати адресу», «Мої адреси», «Де працює», «Як користуватись», «Сайт стеження». У власника є ще «Адмін-панель».

## Звідки беруться години

Офіційна сторінка Волиньобленерго віддає графік картинкою. Публічне посилання на сьогоднішню і завтрашню картинку лежить тут:

`https://api-voe-poweron.inneti.net/api/options?option_key=pw_gpv_image_today`

`https://api-voe-poweron.inneti.net/api/options?option_key=pw_gpv_image_tomorrow`

Порожнє значення на завтра означає, що графік на завтра ще не опублікували. Це не те саме, що «відключень немає».

На безкоштовному тарифі Cloudflare цілу картинку не можна прочитати за один захід: не вистачає ліміту процесора. Тому сервер читає її короткими кроками, складає години для кожної черги від 1.1 до 6.2 і вже потім розсилає зміни. Перевірка запускається кожні 5 хвилин. Повідомлення йде лише тоді, коли години справді інші.

Перше повідомлення по адресі не починається словами «Графік змінився». Ці слова з’являються, коли в той самий день години стали іншими.

## Адмін-панель

Власник бота — чат з `TELEGRAM_ADMIN_CHAT_ID` у файлі доступів. У боті натисніть «Адмін-панель» або надішліть `/admin`. Бот дасть посилання на сторінку.

На сторінці видно кількість користувачів, кількість адрес і список населених пунктів: місто або село, район, вулиця, будинок, черга. Нижче ті самі адреси розкладені по людях. Інший чат цю кнопку не бачить.

## Як підключитися з ноутбука чи іншої програми

У корені архіву є `ДОСТУПИ.env` і `перевірити-доступ.sh`. На ноутбуці розпакуйте архів, відкрийте термінал у цій теці і виконайте:

```bash
bash перевірити-доступ.sh
```

Скрипт викликає Telegram, Cloudflare і сторінку бота. У відповіді має бути ім’я бота `volunsvitlo_bot`, дійсний ключ Cloudflare і `ok: true` зі сторінки здоров’я.

Ті самі значення підходять для Postman, Insomnia, curl або власного скрипта. Підставте змінні з `ДОСТУПИ.env`.

Перевірити бота:

```bash
curl "https://api.telegram.org/bot${TELEGRAM_BOT_TOKEN}/getMe"
```

Поки вебхук увімкнений, метод `getUpdates` відповідає конфліктом. Так і задумано: повідомлення забирає Cloudflare. Щоб читати їх самостійно на ноутбуці, спочатку зніміть вебхук:

```bash
curl "https://api.telegram.org/bot${TELEGRAM_BOT_TOKEN}/deleteWebhook"
```

Після цього хмарний бот перестане отримувати нові повідомлення, доки вебхук не повернете:

```bash
curl -X POST "https://api.telegram.org/bot${TELEGRAM_BOT_TOKEN}/setWebhook" \
  -H "Content-Type: application/json" \
  -d "{\"url\":\"${WEBHOOK_URL}\",\"secret_token\":\"${WEBHOOK_SECRET}\",\"allowed_updates\":[\"message\",\"callback_query\"]}"
```

Перевірити ключ Cloudflare:

```bash
curl "https://api.cloudflare.com/client/v4/accounts/${CLOUDFLARE_ACCOUNT_ID}/tokens/verify" \
  -H "Authorization: Bearer ${CLOUDFLARE_API_TOKEN}"
```

Стан бота без секретів:

```bash
curl "https://pavlo-telegram-bot.pmodsp.workers.dev/health"
```

Запустити перевірку графіка вручну:

```bash
curl -X POST "https://pavlo-telegram-bot.pmodsp.workers.dev/tick" \
  -H "X-Import-Secret: ${IMPORT_SECRET}" \
  -H "Content-Type: application/json" \
  -d "{}"
```

Залити нову версію коду з ноутбука, з теки `svitlo/worker`, після `npm install`:

```bash
export CLOUDFLARE_API_TOKEN
export CLOUDFLARE_ACCOUNT_ID
npx wrangler deploy
```

Секрети `TELEGRAM_TOKEN`, `WEBHOOK_SECRET` і `IMPORT_SECRET` уже записані в Cloudflare. Повторно їх викладати не потрібно, якщо ви їх не міняли. Нове значення задається так:

```bash
printf '%s' "$WEBHOOK_SECRET" | npx wrangler secret put WEBHOOK_SECRET
```

## Локальна програма

Python-програма в теці `svitlo` вміє те саме: сторінка, база адрес і довге опитування Telegram. Зараз на сервері цієї сесії вона запущена з `SVITLO_TELEGRAM=0`, тобто сторінку може показувати, а в Telegram не пише. Пише хмарний бот, щоб люди не отримували одне й те саме двічі.

Щоб підняти її на ноутбуці:

```bash
python3 -m pip install pillow
cd тека-де-лежить-svitlo
SVITLO_HOST=127.0.0.1 SVITLO_PORT=8765 SVITLO_TELEGRAM=0 python3 -m svitlo
```

Сторінка буде на `http://127.0.0.1:8765`. База за замовчуванням — `svitlo/data/svitlo.db`. У архіві лежить копія цієї бази. Живі адреси після переносу на Cloudflare можуть бути новіші: їх видно в адмін-панелі.

Щоб локальна програма сама відповідала в Telegram, спочатку зніміть вебхук командою вище і запустіть з `SVITLO_TELEGRAM=1`. Токен вона візьме з бази або його можна ще раз зберегти на сторінці в розділі Telegram.

Пошук нової адреси просто з сайту Волиньобленерго з локальної програми потребує відкритого Chrome і змінної `SVITLO_LIVE_SEARCH=1`. На Cloudflare цього кроку немає: там працює вже зібраний довідник. Якщо адреси в довіднику немає, бот пише: «Вашої адреси немає в графіках відключень.»

## Що вміє безкоштовний сервер

Бот залишається увімкненим, коли ноутбук вимкнений. Тариф Cloudflare безкоштовний: близько 100 тисяч запитів на добу і короткий ліміт процесора на один захід. Картинки-картки, які малює локальна програма через Pillow, з сервера не надсилаються. З сервера приходить той самий текст з годинами.
